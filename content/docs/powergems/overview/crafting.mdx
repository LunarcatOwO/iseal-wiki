These are the default recipes. Server owners can change them in `recipes.yml`; see
[Advanced Configs](/powergems/fundamentals/getting-set-up/configuration/advanced-configs).

## Crafting a new gem

The default recipe gives you a **random gem**:

- **Corners:** Netherite Block
- **Edges:** Diamond Block
- **Center:** Nether Star

<Callout type="idea">
  If you change this recipe in `recipes.yml`, let your players know (for example by replacing the
  image above) so they know how to craft it.
</Callout>

## Upgrading gems

Put a gem in the middle of the crafting grid with the upgrade materials around it to raise it one
level. By default every level uses the same recipe:

- **Corners:** Netherite Ingot
- **Edges:** Bottle o' Enchanting
- **Center:** the gem you're upgrading

Each level's recipe can be changed separately in `recipes.yml`. Gems go up to level 5 by default
(`maxGemLevel`).

<Callout type="warn">
  The emerald in the middle of the picture stands for the gem you're upgrading, not an actual emerald.
</Callout>

<figure>
	<img src="/images/gem_upgrade.png" alt="Default gem upgrade recipe" />
	<figcaption>The default gem upgrade recipe. The emerald in the middle is your gem.</figcaption>
</figure>

<Callout title="What upgrading gets you" type="info">
  Every level makes most abilities stronger and takes `cooldownBoostPerLevelInSeconds` (2 seconds by
  default) off each cooldown. By default the gem's passive effect starts once it's above level 3.
</Callout>
