title: Advanced Configs
description: The files for recipes, cooldowns, enabled gems, names, lore, materials, particles and passive effects.
---

<Callout title="Where to find the files" type="idea">
  Open your server's files, go to `plugins/PowerGems/`, and open the `config` folder. It holds the
  files below.
</Callout>

<Callout title="Restart after editing" type="warn">
  After changing any of these files, **fully restart your server**. `/reloadconfig` (`/rc`) doesn't
  reliably apply config changes.
</Callout>

## Files at a glance

| File | What it controls |
| --- | --- |
| `recipes.yml` | Crafting recipes for new gems and for each upgrade level. |
| `cooldowns.yml` | The starting cooldown of every ability. |
| `activeGems.yml` | Turn individual gems on or off. |
| `GemNames.yml` | The display name of each gem. |
| `GemLore.yml` | The lore (description) on each gem. |
| `gemMaterials.yml` | The item each gem is based on ([material list](https://jd.papermc.io/paper/1.21/org/bukkit/Material.html)). |
| `GemParticles.yml` | The particles each gem shows. |
| `GemPermanentEffects.yml` | Each gem's passive effect. |
| `GemPermanentEffectLevels.yml` | The level of each gem's passive effect. |

<Callout title="Names and lore support MiniMessage" type="idea">
  Gem **names** and **lore** use [MiniMessage](https://docs.advntr.dev/minimessage/format.html)
  formatting, so tags like `<gradient:#ff5555:#55ff55>`, `<bold>` and color names work. Names aren't
  italic unless you ask for it with `<italic>`.
</Callout>

## recipes.yml

Each recipe has a **shape** and **ingredients**:

- **`shape`** is the 3×3 grid as three rows of letters, separated by commas.
- **`ingredients`** maps each letter to a [material name](https://jd.papermc.io/paper/1.21/org/bukkit/Material.html).

The new gem recipe is `gem_craft_recipe`. Upgrade recipes are named `<gem>_<level>_upgrade`, where
`<level>` is the level the gem is upgraded *to*, and the letter `g` in the shape is the gem itself.

```yaml
gem_craft_recipe:
  shape: ndn,dgd,ndn
  ingredients:
    n: NETHERITE_BLOCK
    d: DIAMOND_BLOCK
    g: NETHER_STAR
fire_2_upgrade:
  shape: nen,ege,nen
  ingredients:
    n: NETHERITE_INGOT
    e: EXPERIENCE_BOTTLE
```

## cooldowns.yml

The cooldown of each ability, in seconds, before level reductions. Every level takes
`cooldownBoostPerLevelInSeconds` off this (see [General Config](/powergems/fundamentals/getting-set-up/configuration/general-config)).

There's one entry per ability, named `<Gem>Gem<Left|Right|Shift>Cooldown`. All of them default to
`60`:

```yaml
FireGemLeftCooldown: 60
FireGemRightCooldown: 60
FireGemShiftCooldown: 60
```

With the defaults, a level 3 gem has a cooldown of 60 − (2 × 3) = 54 seconds.

## activeGems.yml

Turn gems on or off, like `FireGemActive: true`. Turned off gems aren't handed out at random or crafted.

## GemNames.yml

The display name of each gem, like `FireGemName: <green>Fire Gem`. Ignored when `randomizedColors`
is on in `config.yml`.
