---
title: Configuration
description: Where PowerGems keeps its settings and what each file does.
---

PowerGems keeps its settings in `plugins/PowerGems/`:

- `config.yml` holds the general gameplay options.
- The `config` folder holds the files for recipes, cooldowns, gem names, lore and more.

<Callout title="Restart after editing" type="warn">
  After editing any of these files, **fully restart your server** so the changes take effect.
</Callout>
