---
title: API Usage
description: Add your own gems to PowerGems with the addon API.
---

PowerGems has an API that lets other plugins add **new gems**. Your gem works just like the built-in
ones: it gets its own name, lore, cooldowns, passive effect, particles and crafting recipes in the
config files, and can be given out, crafted and upgraded.

- **Server:** Paper 1.20.1+
- **Needed on the server:** PowerGems and SealLib
- **Java:** 21
