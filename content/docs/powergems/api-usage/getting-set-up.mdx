This guide walks you through building a small addon plugin that adds one new gem.

<div className='fd-steps [&_h3]:fd-step'>

### Add the dependencies

Add the iseal.dev repository, then Paper, SealLib and PowerGems as `compileOnly` / `provided`
dependencies. They're already on the server, so don't shade them into your jar.

```kotlin tab="Gradle (Kotlin)"
repositories {
    mavenCentral()
    maven("https://repo.papermc.io/repository/maven-public/")
    maven("https://maven.iseal.dev/repository/maven-public/")
}

dependencies {
    compileOnly("io.papermc.paper:paper-api:1.20.1-R0.1-SNAPSHOT")
    compileOnly("dev.iseal:SealLib:1.2.0.1")
    compileOnly("dev.iseal:PowerGems:3.6.4.3")
}

java {
    toolchain.languageVersion.set(JavaLanguageVersion.of(21))
}
```

```xml tab="Maven"
<properties>
  <maven.compiler.release>21</maven.compiler.release>
</properties>

<repositories>
  <repository>
    <id>papermc</id>
    <url>https://repo.papermc.io/repository/maven-public/</url>
  </repository>
  <repository>
    <id>iseal.dev</id>
    <url>https://maven.iseal.dev/repository/maven-public/</url>
  </repository>
</repositories>

<dependencies>
  <dependency>
    <groupId>io.papermc.paper</groupId>
    <artifactId>paper-api</artifactId>
    <version>1.20.1-R0.1-SNAPSHOT</version>
    <scope>provided</scope>
  </dependency>
  <dependency>
    <groupId>dev.iseal</groupId>
    <artifactId>SealLib</artifactId>
    <version>1.2.0.1</version>
    <scope>provided</scope>
  </dependency>
  <dependency>
    <groupId>dev.iseal</groupId>
    <artifactId>PowerGems</artifactId>
    <version>3.6.4.3</version>
    <scope>provided</scope>
  </dependency>
</dependencies>
```

Use the same SealLib and PowerGems versions that your server runs.

### Create plugin.yml

Depend on PowerGems and SealLib so your plugin loads after them.

```yaml
name: PowerGemsAddon
main: dev.yourname.powergemsaddon.AddonMain
version: 1.0.0
api-version: '1.20'
authors: [YourName]
depend: [SealLib, PowerGems]
```

### Write your gem

Create a class that extends `dev.iseal.powergems.misc.AbstractClasses.Gem`. It needs a constructor
with no arguments that passes your gem's name to `super`.

```java
package dev.yourname.powergemsaddon.gems;

import dev.iseal.powergems.misc.AbstractClasses.Gem;
import org.bukkit.Particle;
import org.bukkit.block.data.BlockData;
import org.bukkit.entity.Player;
import org.bukkit.potion.PotionEffectType;

import java.util.ArrayList;
import java.util.List;

public class ExampleGem extends Gem {

    public ExampleGem() {
        super("Example"); // the gem's name, also used in the config files
    }

    @Override
    protected void rightClick(Player plr, int level) {
        plr.sendMessage("Right click! Level " + level);
    }

    @Override
    protected void leftClick(Player plr, int level) {
        plr.sendMessage("Left click! Level " + level);
    }

    @Override
    protected void shiftClick(Player plr, int level) {
        plr.sendMessage("Shift click! Level " + level);
    }

    @Override
    public ArrayList<String> getDefaultLore() {
        // MiniMessage is supported; <level> is replaced with the gem's level
        return new ArrayList<>(List.of(
                "<gray>Level <level>",
                "<white>Right click: says hello"
        ));
    }

    @Override
    public PotionEffectType getDefaultEffectType() {
        return PotionEffectType.SPEED; // default passive effect
    }

    @Override
    public int getDefaultEffectLevel() {
        return 1;
    }

    @Override
    public Particle getDefaultParticle() {
        return Particle.CRIT;
    }

    @Override
    public BlockData getParticleBlockData() {
        return null; // only needed for block particles
    }
}
```

The `level` passed to each ability is the gem's current level, so you can make abilities stronger as
the gem is upgraded. Cooldowns, WorldGuard regions and CombatLogX tagging are handled for you.

### Register the gem

Register your gem class with `dev.iseal.powergems.api.ApiManager` in your plugin's `onEnable`.

```java
package dev.yourname.powergemsaddon;

import dev.iseal.powergems.api.ApiManager;
import dev.yourname.powergemsaddon.gems.ExampleGem;
import org.bukkit.plugin.java.JavaPlugin;

public class AddonMain extends JavaPlugin {
    @Override
    public void onEnable() {
        boolean ok = ApiManager.getInstance().registerGemClass(ExampleGem.class, this);
        if (!ok) {
            getLogger().warning("Failed to register ExampleGem");
        }
    }
}
```

<Callout type="warn">
  Gems can only be registered while the server is starting up. Registering later (for example from a
  command or a delayed task) is refused.
</Callout>

### Build and test

Build your jar and put it in the server's `plugins/` folder next to PowerGems and SealLib, then
start the server. Your gem gets its own entries in the config files (name, lore, cooldowns, recipes
and so on) and can be given with `/givegem Example`.

</div>

## Tips

- **Match versions.** Compile against the same SealLib and PowerGems versions your server runs.
- **Use the `level`.** Scale damage, durations and radii with the gem's level so upgrades feel worth it.
- **Get help** on the community [Discord](https://discord.iseal.dev).
