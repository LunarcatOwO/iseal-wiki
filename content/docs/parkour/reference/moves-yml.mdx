`moves.yml` holds the settings for the eight moves. Every move has the same few shared settings plus
its own. For what each value does in play, see the individual [move pages](/parkour/moves).

## Shared settings

| Setting | Meaning |
| --- | --- |
| `enabled` | Whether the move exists on the server. |
| `default_unlocked` | Whether new players get the move automatically. |
| `cooldown` | Cooldown after use, in ticks (20 ticks = 1 second). The roll has three cooldowns instead, and the tic tac uses charges. |
| `bossbar.name` | Name shown on the cooldown boss bar (MiniMessage supported). |
| `bossbar.color` | Boss bar color: `PINK`, `BLUE`, `RED`, `GREEN`, `YELLOW`, `PURPLE` or `WHITE`. |
| `bossbar.overlay` | Boss bar style: `PROGRESS`, `NOTCHED_6`, `NOTCHED_10`, `NOTCHED_12` or `NOTCHED_20`. |
| `bossbar.flags` | Extra boss bar effects: `PLAY_BOSS_MUSIC`, `DARKEN_SCREEN` or `CREATE_WORLD_FOG`. |

<Callout title="Updating from an older version" type="info">
  Some settings were renamed or added in newer versions: `wall_cling.cooldown_ticks` is now
