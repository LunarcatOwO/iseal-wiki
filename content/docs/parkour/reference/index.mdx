## Common conventions

- **Ticks:** Minecraft runs at 20 ticks per second. A `cooldown` of `40` = 2 seconds.
- **Velocity values** (e.g. `0.5`) are in blocks-per-tick and are deliberately small; treat them as
  relative dials rather than real-world units.
- **`enabled`** turns a feature on or off entirely.
- **Colors** use Bukkit boss-bar colors (`PURPLE`, `GREEN`, `BLUE`, `YELLOW`, `WHITE`, …).
- **Display names** use [MiniMessage](https://docs.advntr.dev/minimessage/format.html) formatting —
  gradients, colors and decorations like `<bold>` and `<gradient:#a:#b>`.

## Applying changes

After editing any file, run:

```text
/parkour reload
```

to re-read `config.yml`, `moves.yml` and `bonuses.yml` without a restart.

<Callout title="Not everything reloads" type="warn">
  A reload does not re-apply every value. Some move and bonus settings — including all the
  `max_streak_time` values — are only picked up on startup, as are database settings. **Restart the
  server** if a change doesn't seem to take effect.
</Callout>
