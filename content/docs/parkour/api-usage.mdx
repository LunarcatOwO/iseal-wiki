Other plugins can hook into Parkour Project in two ways:

- **Events** let you react to (and cancel) moves, flow changes, door breaches and move damage.
- **Addons** let you add your own **moves**, **style bonuses** and **cooldown displays**.

<Callout type="info">
  Build against **Java 21** and the same Paper version as your server (1.21.11+), and add `SealLib`
  and `ParkourProject` as dependencies in your `plugin.yml`.
</Callout>

## plugin.yml

```yaml
name: MyParkourAddon
main: dev.yourname.myparkouraddon.AddonMain
version: 1.0.0
api-version: '1.21'
depend: [SealLib, ParkourProject]
```

## Events

Listen to these like any other Bukkit event. All of them are in `dev.iseal.parkour.event.sync` and
can be cancelled.

| Event | Fired when |
| --- | --- |
| `PlayerExecuteMoveEvent` | A player is about to perform a move. Cancel it to stop the move. |
| `PlayerChangeStateEvent` | A player starts or stops wall running, sliding, clinging or climbing. |
| `PlayerFlowChangeEvent` | A player's flow score changes, from a bonus or from the drain. Gives the old and new score and rank. |
| `PlayerBreachObstacleEvent` | A sliding player is about to smash through a door, trapdoor or fence gate. |
| `EntityDamagedByMoveEvent` | A move is about to damage a mob: a slide tackle, a roll crush or a tic tac. |

There are also `Async` versions of the move, state and flow events in `dev.iseal.parkour.event.async`.
They fire after the fact and can't be cancelled; use them for things like logging or statistics.
Whether they run off the main thread is controlled by `async-events` in
[`config.yml`](/parkour/configuration).

```java
package dev.yourname.myparkouraddon;

import dev.iseal.parkour.event.sync.PlayerExecuteMoveEvent;
import org.bukkit.event.EventHandler;
import org.bukkit.event.Listener;

public class NoSlidingInSpawn implements Listener {

    @EventHandler
    public void onMove(PlayerExecuteMoveEvent event) {
        var player = event.getPlayer().getPlayer();
        if (event.getMove().id().equals("slide")
                && player.getWorld().getName().equals("spawn")) {
            event.setCancelled(true);
        }
    }
}
```

## Addons

<Callout title="Early access" type="warn">
  The addon API is still in early access and may change between versions. To use it, the server
  needs **`early-bird: true`** in [`config.yml`](/parkour/configuration). Ask on the
  [Discord](https://discord.iseal.dev) before building something big on it.
</Callout>

An addon is a class that extends `dev.iseal.parkour.api.types.ParkourProjectAddon`. Each method
returns a list; return an empty list for anything you don't add.

| Method | Returns | Purpose |
| --- | --- | --- |
| `getPlugin()` | `JavaPlugin` | Your plugin. |
| `getMoves()` | `List<ParkourMove>` | Your own moves. |
| `getBonuses()` | `List<FlowBonus>` | Your own style bonuses. |
| `getCooldownUIs()` | `List<AbstractCooldownUI>` | Your own cooldown displays. |
| `getDependencies()` | `List<ParkourProjectAddon>` | Other addons yours needs. |

### Extend `ParkourProjectAddon`

```java
package dev.yourname.myparkouraddon;

import dev.iseal.parkour.api.types.ParkourProjectAddon;
import dev.iseal.parkour.cooldown.ui.AbstractCooldownUI;
import dev.iseal.parkour.flow.bonus.types.FlowBonus;
import dev.iseal.parkour.moves.ParkourMove;
import org.bukkit.plugin.java.JavaPlugin;

import java.util.List;

public class MyAddon extends ParkourProjectAddon {

    private final JavaPlugin plugin;

    public MyAddon(JavaPlugin plugin) {
        this.plugin = plugin;
    }

    @Override
    public JavaPlugin getPlugin() {
        return plugin;
    }

    @Override
    public List<ParkourMove> getMoves() {
        return List.of();
    }

    @Override
    public List<FlowBonus> getBonuses() {
        return List.of();
    }

    @Override
    public List<AbstractCooldownUI> getCooldownUIs() {
        return List.of();
    }

    @Override
    public List<ParkourProjectAddon> getDependencies() {
        return List.of();
    }
}
```

### Register it in `onEnable`

```java
package dev.yourname.myparkouraddon;

import dev.iseal.parkour.api.ApiManager;
import org.bukkit.plugin.java.JavaPlugin;

public class AddonMain extends JavaPlugin {
    @Override
    public void onEnable() {
        ApiManager.getInstance().registerAddon(new MyAddon(this));
    }
}
```

### Tips

- **Register during `onEnable`**, once per addon.
- **Bonuses** extend one of the classes in `dev.iseal.parkour.flow.bonus.types`: `FlowBonus` for
  basic bonuses, or `AdvancedFlowBonus`, `CombatBonus` or `MythicFlowBonus` for the higher tiers,
  which come with the matching name style and award effects.
- **Cooldown displays** extend `AbstractCooldownUI`, like the built-in `BOSSBAR`, `CHAT` and `TOOLBAR`.
- **Match versions.** Compile against the same SealLib and Parkour Project versions your server runs.
