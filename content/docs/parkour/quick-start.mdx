<Callout type="warn">
  Parkour Project needs a plugin-capable server. We recommend [PaperMC](https://papermc.io/downloads/paper)
  (1.21.11+). [Folia](https://papermc.io/software/folia) is also supported.
</Callout>

<div className='fd-steps [&_h3]:fd-step'>

### Install SealLib
Parkour Project needs **SealLib**. Download it from [Modrinth](https://modrinth.com/plugin/seallib)
and put it in your server's `plugins/` folder.

### Install Parkour Project
Download Parkour Project from [Modrinth](https://modrinth.com/plugin/parkourproject) and put the jar in
`plugins/` next to SealLib.

### Start the server
Start the server once. Parkour Project creates its configuration files in
`plugins/ParkourProject/config/`:

- `config.yml` holds the core plugin settings.
- `moves.yml` holds the settings for each move.
- `bonuses.yml` holds the settings for every style bonus.

### Configure (optional)
The defaults are playable out of the box. To change something, edit the file and run
`/parkour reload`, or restart the server. See [Configuration](/parkour/configuration) for details.

### Try it in-game
Join in **Survival** or **Adventure** mode (moves are turned off in Creative and Spectator) with an
empty hand, and start moving:

- **Sprint and jump** alongside a wall to **wall run** on it.
- While sprinting, **tap sneak** to **slide**.
- Press **sneak** just before you land from a big fall to **roll**.

Run `/parkour moves list` to see which moves you have.

</div>

## Check the install

```text
/parkour moves list
```

You should see your list of moves. If the command isn't found, check the server console for a
missing SealLib or a SealLib version mismatch.
