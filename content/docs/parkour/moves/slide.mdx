title: Slide

The **Slide** is the most versatile move. Slide to get a burst of speed, slip under low gaps,
**smash through doors and gates**, and **tackle** mobs out of your way. Jump out of a slide the
instant it starts for a *wavedash*.

## How to perform

1. **Sprint** on the ground.
2. **Tap sneak** (press and release quickly). You drop into a slide and speed up, then slowly lose
   speed.
3. The slide ends when you slow down too much. To end it early, **tap sneak again** or **jump**.

Downhill slopes keep you sliding further.

### Breaching
Slide into a **door, trapdoor or fence gate** fast enough and you smash straight through it. It
bursts open and swings shut again a moment later.

### Tackling
Slide into a **mob** fast enough to knock it back and damage it.

## Main settings (`moves.yml` → `slide`)

| Key | Default | Meaning |
| --- | --- | --- |
| `min_start_speed` | `0.05` | Speed you need to start a slide. |
| `min_slide_speed` | `0.1` | The slide ends when you drop below this speed. |
| `slide_boost` | `0.3` | Speed boost when the slide starts. |
| `slide_tick_boost` | `0.2` | Extra boost during the slide. |
| `slide_boost_decay` | `0.75` | How fast the boost fades. |
| `down_force` | `0.1` | How strongly you're kept on the ground and on slopes. |
| `flat_friction` | `0.995` | How much speed you keep each tick on flat ground. `0.995` loses 0.5% per tick; lower values stop you sooner, closer to `1` slides further. Slopes slide further automatically. |
| `jump_cancel_force` | `0.095` | Upward boost when you jump out of a slide. |
| `tap_window_ticks` | `5` | How quickly you have to release sneak for it to count as a tap, in ticks. |
| `max_distance_from_ground` | `1.0` | How far off the ground you can be and still slide. |
| `cooldown` | `40` | Cooldown after a slide, in ticks (2 seconds). |
| `bossbar` | Slide / `BLUE` | Name, color and style of this move's cooldown boss bar. |

## Breaching settings

| Key | Default | Meaning |
| --- | --- | --- |
| `max_breach_distance` | `1.5` | How far ahead a door can be to breach it, in blocks. |
| `door_open_time` | `20` | Ticks a breached door or gate stays open before shutting. |
| `min_slide_speed_wooden_door` | `0.2` | Speed needed to breach a wooden door. |
| `min_slide_speed_iron_door` | `0.2` | Speed needed to breach an iron door. |
| `min_slide_speed_wooden_trapdoor` | `0.2` | Speed needed to breach a wooden trapdoor. |
| `min_slide_speed_iron_trapdoor` | `0.2` | Speed needed to breach an iron trapdoor. |
| `min_slide_speed_fence_gate` | `0.2` | Speed needed to breach a fence gate. |

### Breach sounds

Each obstacle type has a **breach** sound (when you smash through) and a **close** sound (when it
swings shut). Any Minecraft sound key works.

| Key | Default |
| --- | --- |
| `wooden_door_breach_sound` | `minecraft:entity.zombie.attack_wooden_door` |
| `wooden_door_close_sound` | `minecraft:block.wooden_door.close` |
| `iron_door_breach_sound` | `minecraft:entity.iron_golem.hurt` |
| `iron_door_close_sound` | `minecraft:block.iron_door.close` |
| `wooden_trapdoor_breach_sound` | `minecraft:item.shield.break` |
| `wooden_trapdoor_close_sound` | `minecraft:block.wooden_trapdoor.close` |
| `iron_trapdoor_breach_sound` | `minecraft:item.shield.break` |
| `iron_trapdoor_close_sound` | `minecraft:block.iron_trapdoor.close` |
| `fence_gate_breach_sound` | `minecraft:entity.zombie.attack_wooden_door` |
| `fence_gate_close_sound` | `minecraft:block.fence_gate.close` |

## Tackle settings

| Key | Default | Meaning |
| --- | --- | --- |
| `tackle_damage` | `3.0` | Damage dealt to a tackled mob. |
| `tackle_min_speed` | `0.15` | Speed needed to tackle. |
| `tackle_radius_x` | `1.5` | Tackle reach to the sides, in blocks. |
| `tackle_radius_y` | `1.0` | Tackle reach up and down, in blocks. |
| `tackle_radius_z` | `1.5` | Tackle reach forward and back, in blocks. |
