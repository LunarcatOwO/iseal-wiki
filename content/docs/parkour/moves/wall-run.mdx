---
title: Wall Run
description: Run along vertical walls to cross gaps and carry your speed.
---

The **Wall Run** lets you run along the side of a wall instead of falling past it. It's the backbone
of vertical routes: chain wall runs together to cross gaps that have no floor.

## How to perform

1. Build up speed by **sprinting**.
2. **Jump** so you're moving alongside a wall, with the wall to your left or right.
3. Keep moving forward and you run along the wall, sliding down slowly as you lose speed.

You need to be moving at roughly sprinting speed to start a wall run, and you can't be sneaking. A
single wall run lasts up to 5 seconds.

Wall runs pair naturally with the [Wall Jump](/parkour/moves/wall-jump) to launch off and the
[Tic Tac](/parkour/moves/tic-tac) to change direction.

## Settings (`moves.yml` → `wall_run`)

| Key | Default | Meaning |
| --- | --- | --- |
| `initial_speed` | `0.6` | Speed you get at the start of the run. |
| `decay_rate` | `0.05` | How quickly you lose speed during the run. |
| `max_fall_speed` | `0.18` | How fast you can slide down the wall. |
| `max_duration` | `100` | Longest a single wall run can last, in ticks (5 seconds). |
| `grace_period_ticks` | `6` | How long you can lose contact with the wall without the run ending. |
| `min_start_speed` | `0.25` | Speed you need to start a wall run. Walking is about `0.22` and sprinting about `0.28`. |
| `vertical_booster` | `0.05` | Small upward push during the run. |
| `wall_push` | `0.06` | How strongly you're kept against the wall. `0` turns it off. |
| `cooldown` | `20` | Cooldown after the run ends, in ticks (1 second). |
| `bossbar` | Wall Run / `PURPLE` | Name, color and style of this move's cooldown boss bar. |
