---
title: Commands & Permissions
description: The /parkour command, every subcommand, and the permissions that gate them.
---

Everything runs through one command: **`/parkour`** (alias **`/pk`**). Running it on its own opens
the in-game help menu, where every entry can be clicked.

<Callout type="info">
  Arguments in `<angle brackets>` are required and `[square brackets]` are optional. When a
  `[player]` argument is left out, the command targets **you**. Targeting someone else needs the
  `parkourproject.parkour.other` permission.
</Callout>

## Moves

Manage which moves a player can use. The **move IDs** are `wall_run`, `wall_jump`, `wall_cling`,
`climb_vault`, `quick_vault`, `slide`, `roll` and `tic_tac`.

| Command | Description | Permission |
| --- | --- | --- |
| `/parkour moves list [player]` | List the player's moves and their cooldowns. | Everyone |
| `/parkour moves enable [move] [player]` | Turn a move on. Leave out the move to get a clickable list. | Everyone |
| `/parkour moves disable [move] [player]` | Turn a move off. | Everyone |
| `/parkour moves enableall [player]` | Turn every move on. | Everyone |
| `/parkour moves disableall [player]` | Turn every move off. | Everyone |
| `/parkour moves unlock <move> [player]` | Give a player a move. | Admin |
| `/parkour moves lock <move> [player]` | Take a move away from a player. | Admin |

<Callout title="Enable and disable vs. unlock and lock" type="info">
  **Unlock** and **lock** decide whether a player *has* a move at all. **Enable** and **disable**
  let a player switch a move they have on or off, for example to stop sliding by accident.
</Callout>

## Cooldowns

View and change move cooldowns. Amounts are in **ticks** (20 ticks = 1 second).

| Command | Description | Permission |
| --- | --- | --- |
| `/parkour cooldowns get [player]` | Show a player's active cooldowns and the time left on each. | Everyone |
| `/parkour cooldowns add <move> <amount> [player]` | Put a move on cooldown for `amount` ticks. | Admin |
| `/parkour cooldowns clear [player]` | Clear all of a player's cooldowns. | Admin |

```text
# Put Steve's slide on a 10-second (200-tick) cooldown
/parkour cooldowns add slide 200 Steve
```

<Callout type="info">
  Tab completion suggests common amounts: `100`, `200`, `600` and `1200` (5, 10, 30 and 60 seconds).
</Callout>

## Cooldown displays

Choose how a player sees their remaining cooldowns. The options are **`BOSSBAR`**, **`CHAT`** and
**`TOOLBAR`** (the action bar above the hotbar). Any number can be on at once, and new players start
with `BOSSBAR` and `TOOLBAR`.

| Command | Description | Permission |
| --- | --- | --- |
| `/parkour ui cooldowns list` | List the cooldown displays and which ones are on. | Everyone |
| `/parkour ui cooldowns enable <ui_name> [player]` | Turn on a cooldown display. | Everyone |
| `/parkour ui cooldowns disable <ui_name> [player]` | Turn off a cooldown display. | Everyone |

## Admin tools

| Command | Description | Permission |
| --- | --- | --- |
| `/parkour reload` | Reload `moves.yml` and `bonuses.yml`. | Admin |
| `/parkour reset [player]` | Reset a player back to normal: stops any move in progress, clears their flow score and potion effects, and restores normal gravity, flight and walk speed. Use it if a player gets stuck. | Admin |
| `/parkour debug [player]` | Show a detailed status report for a player (moves, cooldowns, flow, combo and more). Handy when reporting a bug. | Admin |

## Permissions

| Permission | Default | Grants |
| --- | --- | --- |
| `parkourproject.parkour.other` | op | Use `/parkour` subcommands on **other players** (the `[player]` argument). |
| `parkourproject.parkour.admin` | op | Use the **admin** subcommands: `moves unlock/lock`, `cooldowns add/clear`, `reload`, `reset` and `debug`. |

<Callout type="warn">
  Both permissions default to **op**. On a public server, give them to trusted staff with a
  permissions plugin instead of handing out operator status.
</Callout>
