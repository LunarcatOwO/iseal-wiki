<Callout title="Where to find the file" type="info">
  Open your server's files, go to `plugins/ParkourProject/config/`, and open `config.yml`. This
  file holds the core plugin settings. Move settings live in `moves.yml` and bonus settings live in
  `bonuses.yml`, both covered under [Reference](/parkour/reference).
</Callout>

## Default `config.yml`

```yaml
database:
   table:
      prefix: parkour_project
   username: root
   password: password
early-bird: false
dev-token: none
allow-metrics: true
external-effects: true
async-events: true
```

## Database

Parkour Project saves player data, like which moves each player has and which cooldown displays
they use. It works out of the box with no database setup.

| Option | Default | Description |
| --- | --- | --- |
| `database.table.prefix` | `parkour_project` | Prefix for every table the plugin creates. |
| `database.username` | `root` | Database username. |
| `database.password` | `password` | Database password. |

<Callout type="warn">
  External databases (like MySQL) aren't supported yet, so you can leave these as they are.
</Callout>

## Plugin options

| Option | Default | Description |
| --- | --- | --- |
| `early-bird` | `false` | Opts into early access to features that aren't fully released yet, like the [addon API](/parkour/api-usage). Leave it `false` unless you need one of them. |
| `dev-token` | `none` | Only for development builds. Leave it as `none`. |
| `allow-metrics` | `true` | Sends **anonymous** usage statistics and error reports that help improve the plugin. Set to `false` to opt out of both. |
| `external-effects` | `true` | Plays the extra particles and sounds when a player earns an Advanced, Combat or Mythic bonus. Set to `false` to turn them off. |
| `async-events` | `true` | Handles bonus and flow updates in the background. Setting it to `false` makes the plugin feel more responsive and makes sure bonuses are always awarded in the right order, but it adds to your tick times, which can cause lag if your server's CPU can't keep up. |

## Applying changes

After editing `moves.yml` or `bonuses.yml`, run:

```text
/parkour reload
```

<Callout title="When to restart" type="warn">
  `/parkour reload` reloads `moves.yml` and `bonuses.yml`. Changes to `config.yml` need a full
  **restart**, and so do a few move and bonus settings. If a change doesn't seem to take effect,
  restart the server.
</Callout>
